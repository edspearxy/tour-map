# Tour Map

Product initiative run through the `agentic-sdlc` plugin (edspearxy/agentic-sdlc-toolkit).

- Run gates in order via their skills: `/ideation` → `/discovery` → `/design` → `/build` →
  `/test` → `/release` (+ `/retro`). A gate never starts without the previous gate's
  `<gate>/decision.md` recording a human decision.
- Never copy toolkit rubrics, templates, agents or universal corrections into this repo.
  Project-local learning goes in `memory/corrections/<agent-name>.md` only.
- Review outputs are dated and never overwritten (`<name>-<YYYY-MM-DD>-review.md`, `-2`, `-3`).
- All development is traceable to exactly one tracker issue: one branch and one PR per issue.
- Product owner directs scope and QA; explain choices at decision level, in British English.
